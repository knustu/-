# 군위군 생활시설·소방시설 공개자료

군위군 시설관리 우선지역 분석을 위해 수집한 공개자료입니다. **실제 자료 기준일이 2025년 이후인 자료만 포함**합니다. 확인일: 2026-10-14.

- [생활시설 자료](data/gunwi/living/읽어주세요.md): 보안등, 도시공원, 상수도보급률, 경로당, 자전거도로.
- [소방시설 자료](data/gunwi/fire/읽어주세요.md): 2026년 소방용수시설, 119안전센터, 관할소방서, 구급차 운영 거점 및 소방관서 집계.
- [생활시설 ZIP](downloads/군위군_공개데이터.zip)
- [소방시설 ZIP](downloads/군위군_소방시설_2025이후.zip)

각 폴더의 자료목록.csv에 공식 출처와 기준일을 기록했습니다. 원문 CSV는 UTF-8 BOM으로 인코딩만 변환했고, 군위군 관련 추출본은 별도 파일로 저장했습니다. 포털 수정일을 실제 자료 기준일로 대체하지 않았습니다.

## 확인된 한계

- 소방용수 자료의 일부 주소·관할 표기는 과거 정보입니다. 공개 스냅샷 기준일과 개별 시설 점검일은 다릅니다.
- 보안등 좌표·설치연도는 빈 값이며, 소방기관 자료도 주소 좌표 변환이 필요합니다.
- 개별 민원의 발생 위치·처리 이력과 시설 점검·보수 이력은 포함되지 않습니다. 이 자료만으로 민원 기반 읍면별 관리 우선순위를 확정할 수 없습니다.
- 외부 공간자료는 제공 경로만 기록되어 있으며 실제 SHP 파일은 포함하지 않습니다. SGIS 동봉 2024년 통계는 선정 범위에서 제외됩니다.

원천 자료의 이용조건은 각 공식 출처를 따릅니다. 이 저장소는 공공데이터의 수집·정리본이며 군위군 전체 시설의 최신 전수대장을 보장하지 않습니다.
