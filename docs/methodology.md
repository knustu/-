# 지표 산식과 근거

원칙: **공식 기준과 프로젝트 파생지표를 구분한다.** 근거 없는 합성 지표는
계산하지 않는다. 산식을 바꿀 때는 코드만 고치지 말고 이 문서를 함께 고친다.

---

## 1. 지금 계산하는 것

### 고령화율

```
고령화율(%) = 65세 이상 인구 / 총인구 × 100
```

출처: 행정안전부 주민등록 인구통계, 5세 연령구간의 65세 이상 8개 구간(65~69 …
100세 이상) 합.

주의 — 이 값은 **주민등록 기준**이다. SGIS 격자 통계나 센서스의 고령인구와
모집단이 다르므로 섞어 쓰지 않는다. 외국인은 제외되고 거주불명자·재외국민은
포함된다.

`tools/prepare.py` 가 구간 합계 = 총계, 남+여 = 계, 읍면 합계 = 군 합계를
모두 검증한 뒤에만 이 값을 만든다.

## 2. 원자료가 들어오면 계산할 것

### 민원발생률 — 프로젝트 파생지표

```
인구 1천명당 민원건수 = 유효 민원건수 / 동일 기준시점 주민등록인구 × 1,000
```

법정 산식이 아니라 **지역 간 비교를 위해 프로젝트가 정한 정규화**다. 분자와
분모의 기준시점을 반드시 맞춘다. 관광지·공공시설이 많아 유동인구가 큰 지역은
주민등록인구 분모가 과소 분모가 되므로 이용량 기준을 병행 검토한다.

### 반복민원율

```
반복민원율 = 반복민원 건수 / 유효 민원건수
```

「민원처리에 관한 법률」 제23조의 반복민원은 **3회 이상 + 동일 내용 +
정당한 사유 없음**이 요건이다. 기계적으로는 3회 이상 제출과 동일내용 확인
여부까지만 선별할 수 있고, "동일 내용"의 최종 판단은 처리 기관의 몫이다.
단순 중복신고와 반복민원을 구분하는 기준(동일 시설 / 동일 문제 / 기간)은
담당부서와 합의한 뒤 확정한다.

### 처리지연율

```
처리지연율 = 처리기한 초과 건수 / 평가 대상 건수
```

- 미완료 건을 0일로 처리하지 않는다. 평가 대상에서 분리한다
- 달력일 / 업무일 여부, 연장·보류 기간 제외 여부를 명시한다
- 단순 평균 처리일수로 대체하지 않는다. 기한 초과 여부가 기준이다

### 시설관리 필요도

위치만으로는 판단할 수 없다. **설치연도·점검등급·고장이력·보수일**이 있어야
한다. 현재 확보된 도시공원 3건은 표준데이터 등록분일 뿐 군내 전수가 아니므로,
이것으로 시설밀도나 관리 필요도를 산출하면 과소계상된다.

## 3. 계산하지 않는 것: 종합 우선순위

기존 화면이 쓰던 가중치는 이것이다.

```
0.35 × 민원발생률 + 0.25 × 반복민원율 + 0.25 × 처리지연율 + 0.15 × 시설관리필요도
```

**이 값은 산출하지 않는다.** 이유가 셋이다.

1. **공식 산식이 아니다.** 원 문서에서 제안된 숫자이고 "확정모형이 아님"으로
   기록돼 있다. 공식 기관이 승인한 가중치가 아니다.
2. **척도가 다르다.** 민원발생률은 건/천명, 나머지는 비율(0~1) 또는 점수다.
   표준화 없이 가중합하면 단위가 섞여 숫자의 의미가 사라진다.
3. **검증할 수단이 없다.** 가중치가 맞는지 확인하려면 과거 보수·정비 결과와
   대조해야 하는데 그 이력 자료가 미확보다.

`public/data/regions.json` 의 `priority_score` 는 `status: "blocked"` 이고
값이 존재하지 않는다. `tools/tests/test_build.py` 가 값이 채워지는 것을 막는다.

### 살리려면 먼저 할 일

- 네 지표를 같은 척도로 정규화 (min-max 또는 z-score, 방향 통일)
- 가중치 근거 확보 — AHP/MCDA, 담당부서 합의, 또는 과거 정비결과 회귀
- 가중치 민감도 분석 — 가중치를 흔들어도 상위 지역이 유지되는지
- 이 문서에 근거와 합의 주체를 기록한 뒤 `INDICATORS` 에서 상태를 바꾼다

근거를 만들기 전에는 인구만으로 정비순위를 매기지 않고, 미확보 항목을 0으로
채우지 않는다.

## 4. 결합할 때 주의

- **기준시점 통일** — 파일 수정일과 데이터 기준시점은 다른 개념이다.
  `_meta.json` 이 `retrieved_at` 과 `reference_date` 를 따로 기록하는 이유다
- **행정구역 변동** — 군위군은 2023년 경북 → 대구 편입. 이전 자료는 옛 명칭·
  코드를 쓰므로 검색·결합 시 대응표가 필요하다
- **코드 체계** — 주민등록 행정기관코드와 SGIS 행정동 코드는 다른 체계다
  (`CLAUDE.md` 참고)
- **비공개값** — 통계 비공개 처리된 값을 0으로 변환하지 않는다
- **범례** — 현재 코로플레스 구간은 화면에 보이는 8개 값의 상대 척도다.
  절대 기준이 아니므로 시점 간 색을 직접 비교하지 않는다
