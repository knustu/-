# 군위군 민원 수요 데이터 조사 (data-survey)

조사일: 2026-10-14 · 조사자: agent(data-survey) · 브랜치: `data-survey`

## 0. 이 문서의 목적과 표기 규칙

민원 원자료(군청 내부 처리대장)가 없어 **민원발생률·반복민원율·처리지연율이 모두
미확보**인 상태에서, 공개적으로 구할 수 있는 데이터를 최대한 모아 둔다.
민원 데이터 자체가 아니어도 "여기는 민원이 많겠다"고 근거를 들어 추론할 수 있는
대리지표를 포함한다.

**표기 원칙**

- **데이터를 만들지 않는다.** 샘플값·추정값·보간값은 쓰지 않는다. 없으면 "미확보".
- 상태값: `확보` / `다운로드가능(미수행)` / `API키필요` / `회원가입필요` /
  `청구필요` / `없음(확인)` / `범위밖(시군단위)`
- 상관 가설이 근거 없이 추측이면 **가설(미검증)** 이라 적는다. 실제 민원 데이터가
  들어오면 검증 대상이다.
- 확인하지 못한 URL·오퍼레이션명은 추측해서 적지 않고 "기술문서 확인 필요"로 남긴다.

**행정구역·코드 주의 (조사 중 확인한 사실)**

| 체계 | 군위군 코드 | 비고 |
|---|---|---|
| 주민등록 행정기관코드 | `2772025000` (군위읍), 군 합계 `2772000000` | 프로젝트 표준 |
| 경계 원본 ADM_CD | `22520111` 계열 | 다른 체계 |
| **SGIS 제공용 코드** | **`22520`** (시군구), `22520xxx` (읍면동 8개) | 이번에 다운로드한 SGIS 자료의 실제 코드 |
| 옛 경북 군위군 | `47720` 계열 | 2023-07 이전 |

⚠️ SGIS 제공용 코드는 통계청 최신 행정구역코드(`27720`)와 **다르다.**
문서·검색에서 "27720"을 쓰면 SGIS 파일에서 아무것도 안 잡힌다. 실제로 이번 조사에서
`27720`으로 필터링해 0행이 나왔고, `22520`으로 고쳐서야 군위군 8개 읍면이 나왔다.

## 2. 찾았는데 쓸 수 없던 것 (이유 포함)

- **민원빅데이터 분석정보 API**: `DATA_GO_KR_KEY` 환경변수가 없어 호출 불가. 오퍼레이션
  이름은 기술문서(`민원분석정보조회_v1.0.docx`)에만 있고 포털 HTML에는 없다. 키 발급 후
  오퍼레이션목록 파일(15130836)을 사람이 내려받아 확인해야 한다.
- **data.go.kr 파일 다운로드**: 포털 파일 다운로드가 JS(`fn_fileDataDown`) 게이트라
  목록 HTML에 링크가 없다. 이번에는 포털 내부 엔드포인트(`selectFileDataDownload.do` →
  `cmm/cmm/fileDownload.do`)를 직접 호출해 SGIS zip을 받는 데 성공했다. 나머지 파일도
  같은 방식이 가능하지만, 안정적인 공개 API가 아니므로 사람이 클릭해 받는 편이 낫다.
- **군위군청 게시판**: 목록이 JS로 렌더링되어 `curl`/`web_fetch`로 본문이 안 잡힌다.
  브라우저 도구가 필요하다.
- **SGIS 경계 shp**: 원본 zip 안에 시도/시군구/행정동 경계가 있으나 **EPSG:5179
  (Korea 2000 UTM-K)** 로 투영돼 있다. 이 환경에는 GDAL/geopandas/pyproj가 없어
  위경도 GeoJSON으로 변환하지 못했다. (지도에 쓰려면 재투영 필요.)
- **상수도통계·빈집·축산·119·안전지수** 등: 모두 **시군 단위**까지만 공개. 읍면 8개로
  쪼갤 수 없어 "군 전체 참고용"으로만 남긴다.

## 3. 다음에 사람이 해야 할 일

1. **`DATA_GO_KR_KEY` 발급·등록** → 민원빅데이터 분석정보 API(2022~2025) 호출.
   특히 2024년판의 "민원 발생지별" 오퍼레이션이 **읍면 단위를 주는지** 먼저 확인.
2. **군청 정보공개청구 발송** (`docs/requests/` 참조): 민원 처리대장, 가로등·보안등
   대장, 시설 점검·보수 이력, 상하수도 관망.
3. **SGIS 경계 재투영**: 원본 zip(위 경로)을 GIS 도구로 열어 군위군 읍면 경계를
   위경도로 추출 → `data/raw/boundary-eupmyeon-2025-06-30`의 `provenance` 대조.
   **이게 `CLAUDE.md`의 최우선 과제다.**

5. 회원가입/로그인이 필요한 곳: TAAS, 국가공간정보포털(재해·도로대장), LOCALDATA.
