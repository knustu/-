# 군위군 공공시설 위치자료 추가 조사

확인일: 2026-10-14. **실제 자료 기준일이 2025년 이후인 자료**를 정제에
사용했다. 포털 수정일·파일 수집일·설치일을 자료 기준일로 대체하지 않았다.
2025년 자료는 현재 공개 다운로드에서 확인된 최신본일 때만 채택했다.

## 바로 사용할 파일

- [전체 출처 레지스트리](../data/sources.json): 공식 URL·제공기관·기준일·이용조건·원본 폴더.
- [추가 위치 CSV](../data/derived/additional_facilities.csv): 주소, 지도용 좌표,
  원문 좌표, 분야, 시설 유형, 기준일, 출처 ID·URL, 원본 경로·행 번호.
- [추가 위치 GeoJSON](../data/derived/additional_facilities.geojson): 지도에 사용할 수
  있는 251개 관측. 보건시설 간접 위치 18행은 `proxy_location: true`로 구분.
- [정제 보고서](../data/derived/additional_facilities_report.json): 분야별 행수·제외 내역·좌표 검토 대상.
- [기존 자료 파일별 이관 메타데이터](../data/gunwi/_meta.json): 출발 커밋,
  SHA-256, 원출처 ID, 기준일, 변환·추출 여부.

**259행은 서로 다른 시설 259곳이라는 뜻이 아니다.** 한 장소의 여러 시설 단위와
같은 수거함 행을 공공보건 분야에서 다시 사용한 관측을 포함한다. 위치만으로
시설관리 필요도나 민원 우선순위를 계산하지 않았다. 지도 화면에는 현재 공원
3곳만 표시하며, 추가 파일은 분석용으로 제공한다.

각 `data/raw/` 폴더의 `_meta.json`에 수집일·해시를 기록하고, 배포 파일과
공식 페이지 증빙을 받은 바이트 그대로 보존했다. 원출처 이용조건이 명시된
자료는 해당 조건을 기록했으며, 확인되지 않은 이용허락은 `확인 필요`로 남겼다.
공개 다운로드 가능 여부가 일괄 재배포 허락을 뜻하지는 않는다.

## 사용 전 알아야 할 품질 문제

1. **CCTV 좌표 오류 후보:** 원본 639번째 데이터 행, 관리번호
   `202651410000800116`, 주소 `대구광역시 부계면 창평리 213`의 위도
   `36.851755`, 경도 `128.6946508`은 넓은 군위 범위 밖이다. `reported_latitude`와
   `reported_longitude`에는 원문을 보존하고 지도용 좌표는 비웠다. GeoJSON에서
   제외했으며 주소나 위도를 임의로 고치지 않았다. 115개 위치 행과 카메라 대수도
   서로 다른 개념이다.
2. **기존 원본 줄바꿈:** 기존 주차장·세천 Git CSV는 CRLF가 LF로 바뀌어
   `_meta.json`에 기록된 다운로드 해시와 달랐다. 기존 파일은 수정하지 않고 공식
   URL에서 다시 받아 새 원본 폴더에 등록했다. 재취득 파일은 기존 출처 카드의
   공식 다운로드 해시와 일치한다. `.gitattributes`로 새 원본의 줄바꿈 변환을 막았다.
3. **좌표·경계:** 공공개방시설의 동일 좌표는 원문을 유지했다. 좌표가 없는
   도서관·대피시설을 임의 지오코딩하지 않았다. 기존 행정경계의 `UNVERIFIED`
   상태를 유지했으며 추가 위치자료의 읍면 배정에 사용하지 않았다.
4. **공공보건 간접 위치:** 18행은 수거함 자료로 확인한 시설 소재지이고, 보건시설
   운영·폐업 여부를 별도 확인한 전수대장이 아니다. 폐기물 분야와 함께 합산하면
   같은 원본 행을 중복 계산한다.

## 공개 민원자료

기존에 수집한 [군위 공개 민원 Q&A](../data/gunwi/complaints/) 25행과 도로 관련
4행(포함 관계), 처리기간 준수 기관 집계 1행도 모두 이관했다. 원출처는
[국민신문고 공개 Q&A](https://www.data.go.kr/data/15164540/fileData.do),
[정부민원 처리기간 준수현황](https://www.data.go.kr/data/3070147/fileData.do)이다.
전체 건별 민원대장이 아니고 발생지 좌표가 없어 추가 시설에 자동 연결하지 않았다.
8개 분야의 위치가 있는 최신 시설별 민원 기록은 이번 공개 검색에서 확보하지 못했다.

## 재생성과 이관 검증

```bash
python tools/prepare.py   # 공식 원본 해시 확인 → 추가 CSV·GeoJSON·보고서 생성
python tools/build.py     # 기존 웹 공개 경로 유지; 출처 패널은 전체 레지스트리에서 생성
python -m pytest tools/tests -q
```

출발 저장소 [knustu/-](https://github.com/knustu/-)의 커밋
`3340f8ab0f19b120c9b83504e17875fc21b648de`를 이 저장소 이력에 병합했다.
기존 46개 파일은 README만 `FACILITY_DATA_README.md`로 이름을 바꿔 동일한
바이트로 옮겼다. Git에서 받은 전체 ZIP도 `data/raw/git-facility-import-3340f8a/`에
동결했다. 이 묶음은 이미 변환·추출된 수집파일을 포함하므로 정부 원본 바이트와
동일하다고 표시하지 않는다. 개별 공식 출처는 `data/sources.json`으로 연결했다.
기존 인구·원본 자료와 앱을 유지했고 출발 저장소의 파일을 삭제하지 않았다.
