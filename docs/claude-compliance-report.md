## 남아 있는 문제와 사용 범위

1. **경계 출처 검증 미완료.** SGIS 경계 재취득·대조는 끝나지 않았다.
   추가 시설의 읍면별 밀도나 우선순위 산출 근거로 사용하지 않았다.
2. **기존 원본 해시 불일치 14파일.** 모두 기존 출처 카드의 해시가
   CRLF 줄바꿈을 가정하고 Git 파일은 LF로 저장된 경우다. LF를 CRLF로
   비교할 때 기록된 해시와 일치함을 확인했지만, 실제 동결 파일의 바이트
   해시와 같다고 표시하지 않았다. 원본·출처 카드를 덮어쓰지 않았다.
   추가 시설에 필요한 주차장·세천 CSV는 공식 다운로드를 새 원본 폴더에
   재등록했으며 기존 카드의 공식 다운로드 해시와 정확히 일치한다.
   나머지 기존 불일치 내역은 `docs/claude-compliance-audit.json`에 기록했다.
3. **CCTV 좌표 오류 후보 1행.** 관리번호 `202651410000800116`의 원문
   위도 `36.851755`·경도 `128.6946508`을 보존하고 지도 좌표를 비웠다.
4. **간접·부분 자료.** 보건시설 18행은 수거함 좌표이며, 세천 자료는
   빗물받이·맨홀 전수대장이 아니다. 무더위쉼터·AED·지진대피소 등 최신
   실제 목록을 확보하지 못한 세부 항목은 미확보로 남겼다.
5. **이용조건 확인 필요 항목.** 확인되지 않은 이용허락을 임의로
   ‘제한 없음’으로 바꾸지 않았다. 기관별 조건은 출처 레지스트리를 확인한다.

따라서 **자료 정리·생성 규칙은 준수했지만, 기존 경계의 출처 확인과 기존
해시 불일치 전체 해소까지 완료한 저장소라는 뜻은 아니다.** 확보한 범위 내
시설 위치 분석과 원출처 추적에 사용할 수 있으며, 전수 시설대장이나 민원
우선순위 산출 결과로 사용하면 안 된다.

## 공유 폴더 구성

공유용 폴더 이름은 `군위군`이다. 최상위에 점검 보고서·추가 시설 CSV·
GeoJSON을 두고, `자료/` 아래에는 출처와 원본 경로가 유지되는 저장소 전체
파일을 넣는다. 빠른 확인용 CSV의 `source_raw_file` 경로는 `자료/`를 기준으로 읽는다.
공유 폴더의 파일별 해시는 `공유폴더_메타데이터.json`에 기록한다.

Google Drive의 실제 폴더 생성·업로드·링크 공유 설정은 연결 도구가 제공되어야
실행할 수 있다. 로컬 폴더와 ZIP 준비를 Drive 업로드 완료로 표시하지 않는다.
